# J-PLATPAT PDF公報テキスト化ツール（完全ローカル版）

J-PLATPAT（特許情報プラットフォーム）などからダウンロードした特許公報のPDFを、AIが読み込みやすい最適な形式のテキストファイルに変換するツールです。
2段組レイアウトの正しい順序でのテキスト化と、セキュリティに配慮した完全ローカル動作に対応しています。

---

## 主な機能と特徴

### 1. 2段組公報の正しい順序でのテキスト化
人間の目と同じように「左段を上から下まで読み、次に右段へ」という順序でテキストを再構成します。段落番号（`【０００１】` `【０００２】` など）が崩れることなく抽出できます。

### 2. 画像化された書誌事項のOCR抽出
J-PLATPATのPDFで画像化されている書誌事項（登録番号、出願日、特許権者、IPC分類など）をOCRで読み取り、「項目名：値」の構造化データとして整理します。
* **選択式出力:** OCR処理は若干時間がかかるため、テキストファイルに書誌事項を含めるかどうかをボタン一つで選択可能です。

### 3. セキュリティ安心の「完全ローカル」仕様
外部ライブラリの参照（CDN等）が一切ない、独立したローカルHTMLツールです。
* **オフライン動作:** インターネット接続がなくてもそのまま動きます。
* **外部通信なし:** 読み込んだPDFの内容や抽出データが外部のサーバーに送信されることは仕組み上あり得ません。社内のセキュリティポリシーが厳しい環境でも安心して導入・説明が可能です。

---

## 使い方

1. 本リポジトリからZIPファイルをダウンロードし、解凍します。
2. 解凍されたフォルダ内にある **HTMLファイル** をブラウザ（Chrome/Edgeなど）で開きます。
3. 画面の指示に従ってPDF公報を読み込ませるだけで使用できます。

> [!CAUTION]
> **ファイル構成について**
> ライブラリ群はすべて同梱されています。解凍後に生成されるライブラリフォルダは削除したり、HTMLファイルと離したりしないでください。移動やコピーを行う際は、必ずフォルダごとセットで行ってください。

---

## 本ツールの限界・留意事項

* **図面の抽出はできません:** テキスト化の対象は文字情報のみです。図面をAIに検討させたい場合は、原本のPDFや画像ファイルを併用してください。
* **OCRは100%完全ではありません:** ほぼ正確に読み取れますが、濁点・半濁点の誤認（「ブラシ」と「プラシ」など）や、英数字の誤認（「0」と「O」など）が稀に発生します。重要な書誌事項は出力後に一度目視で確認することをおすすめします。
* **スキャン画像ベースの古い公報は対象外です:** 明細書本体のOCR機能は搭載していません。文字情報（テキストレイヤー）を持つPDF公報でご利用ください。
